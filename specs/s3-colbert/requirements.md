Read both files yourself and follow them exactly.

THE TEST SPLIT IS SEALED: tune and compare on `dev` only.

- R1 `engine/chapterverse/dense/colbert.py`: `ColbertScorer.load(model_dir, manifest)` (sha256 checked, fail closed, CPU, fixed intra-op threads, default 4). `encode_query(text)`, `encode_docs(texts)` (batched, sorted by length), `score(query, docs) -> list[ColbertMatch(score, best_window, span_char_start, span_char_end)]`. The matched span: for the best window, the character range covering the document tokens that won the MaxSim for the most query tokens (use tokenizer offsets); keep it simple and document the rule.
- R2 Windows: for each candidate section, split its text (from `chapterverse.dense.doctext`, without the embedding-only prefix, or from the store records) into subsection windows at top-level subsection markers like `(1)`, `(2)`, never inside an `(a)`/`(b)` paragraph; a section without subsections is one window; prepend the section heading to every window; truncate each window to the document max length. Section score = max over its windows.
