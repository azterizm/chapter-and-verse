# CI fixes: requirements

CI on PR #1 (GitHub Actions, ubuntu-latest and ubuntu-24.04-arm, Python 3.11 and 3.12) fails two tests that pass locally. CI has no real corpus: `artefacts/store` and `LEGAL_DATA_ROOT` are absent.

- R1 `tests/test_audit_classify.py::test_real_offence_provision_confirmed_via_store` opens `artefacts/store` and fails with `StoreLoadError: no corpus-manifest.json in artefacts/store`. It SHALL carry `@pytest.mark.data` and skip unless the store and `LEGAL_DATA_ROOT` are present, like the other real-data tests (see `tests/conftest.py`, `real_data_root`). The offence-provision text needed by the non-data tests SHALL stay as a literal in the test file, so the check is still covered in CI.
- R2 `tests/test_app.py::test_disconnect_stops_the_worker_and_stores_nothing` fails at line 519, `assert all(r.purpose == "generate" for r in rotation.requests[-1:])`: on a slower runner the last request is a judge call. The test's intent is that after a client disconnect the worker stops at the next sentence boundary and stores nothing. The assertion SHALL test that intent without depending on which call type happens to be last (for example: bounded number of requests after the disconnect, no receipt stored). Do not weaken the other assertions. Make the test deterministic: run it 50 times in a row locally with `uv run pytest -q tests/test_app.py -k disconnect --count` style looping (a shell loop is fine) and report the pass count.
