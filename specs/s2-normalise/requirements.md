# Slice 2, stage 1 normalise: requirements

Plan §5 stage 2 (read the plan's §5 at `~/.claude/plans/plan-extensively-to-build-bright-sunset.md`): mask, correct spelling with SymSpell, unmask. Questions without a citation ("unfiar dismisal compensatory award cap") must be corrected before discovery, but citations, identifiers, numbers and years must never be changed.

- R1 `engine/chapterverse/normalise.py`: `normalise(query, *, dictionary) -> Normalised` with fields `text` (corrected query), `corrections` (tuple of (original, corrected) pairs, in order) and `masked_spans` (the protected spans).
- R2 Protected spans, never corrected: everything `legal_rag_router.identifiers.scan_identifiers` finds; citation-like spans the router's UK grammar recognises (read `legal_rag_router` for the public way to get citation spans; `Router.route(query).citations[*].span` is acceptable); any token containing a digit; tokens in ALL CAPS of 2 to 6 letters (acronyms such as ERA, TUPE, PACE); quoted text. Follow the span-list, overlap-resolution, placeholder and reverse-map mechanism of `~/Code/legal-rag-mask/legal_rag_mask/core/` (read it; do not import it). State is per call; no globals.
- R3 SymSpell (`symspellpy`, already a dependency) with a golden dictionary built by `build/symspell_dict.py` from the router's concept index vocabulary (`$LEGAL_DATA_ROOT/concepts`, read through the router's public API or its manifest-described files) plus the words of all instrument titles, with frequencies. Output `artefacts/symspell/dictionary.txt` plus a SHA-256 manifest; deterministic. Report term count, size and build time.
- R4 Correction policy: max edit distance 2; correct a word only if it is not in the dictionary and the best suggestion is unique at the smallest distance; never change words of 3 letters or fewer; keep the original casing pattern. Log the miss rate (words with no suggestion) per call at debug level, never the words.
- R5 Latency: p99 under 5 ms for a 200-character query on this Mac after load; report load time and RSS.
- R6 Tests: "unfiar dismisal" corrected; "s.124 ERA 1996" untouched; "SI 2011/9999" untouched; "Employmnet Rights Act 1996 section 98" corrects only "Employmnet"; acronyms and numbers untouched; empty and 4 KB inputs; determinism.
