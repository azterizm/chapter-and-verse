# Startup fix: requirements

Production incident, 21 Nov 2026: deploying slice-2 (e5b3b52) to the A1 crashed the engine at startup and the site returned 502 for about 10 minutes until it was rolled back to main. Traceback: `app.py` `_load_slice2_dictionary` calls `build_symspell_in_memory(concepts)` with the router's `ConceptIndex`; after the dictionary fix (28e8661) the builder takes the text store or a path, so `Path(ConceptIndex)` raised `TypeError`. Local tests passed because `_load_slice2_dictionary` silently falls back to `<repo>/artefacts/symspell/dictionary.txt`, which exists on the Mac but not in the container.

- R1 `_load_slice2_dictionary(env, store)`: if `SYMSPELL_DICT` names an existing file, load it; otherwise build the dictionary in memory from the already opened text store (the same `TextStore` the runtime uses), using `build_symspell_in_memory(store)`. Remove the repo-relative `artefacts/symspell` fallback entirely: runtime behaviour must not depend on files in the source tree. Make `extract_term_frequencies` accept a `TextStore` instance and iterate its records through public store methods (add a public iteration method to the store only if none exists; prefer reading what is needed through existing methods). Pass explicit types; no `Any` where a Protocol fits.
- R2 Startup must log how the dictionary was obtained (file or built from store), the term count and the seconds taken (no words).
- R3 Test: build the runtime with `create_app`/`build_runtime` from env with NO `SYMSPELL_DICT`, with the repo `artefacts/` directory not consulted (for example run with a temporary working directory or patch the module so no repo path is used), over the fixture store: startup succeeds and a misspelled uncited query gets a corrections notice. This is the path that failed in production.
- R4 Measure on this Mac with the real store (`STORE_DIR=artefacts/store`, `LEGAL_DATA_ROOT=~/Code/legal-rag-router/data`, no `SYMSPELL_DICT`): time from process start to healthy `/api/health` via `uv run python <script under $CV_SCRATCH/s2-startup-fix/>` that starts uvicorn on a free port, polls health, and stops it. Report seconds and RSS.
