# S5.1b Judge on cited passages only (F12): requirements

Each judge call today sends every candidate built from the whole premise (all windows, joined windows, enrichment elements; `legal_rag_verifier.verifier._nli_candidates`), about 1,430 prompt tokens of which 57% is premise. The sentence being judged has already passed the reference rules (`AuditVerifier.check_sentence` in `engine/chapterverse/audit/verify.py`), so we know which passages it cites. Sending the judge only the cited passages cuts judge tokens. This changes what the judge reads, so it is merged only if the sealed judge gates are no worse (orchestrator runs them).

- R1 Engine. In `AuditVerifier`, after the reference and classification checks pass, the entailment judge sees only the candidates whose FIRST window position is a cited passage (a "joined" candidate of a cited window with the window it refers to is kept; an enrichment element of a cited window is kept). Everything else in `Verifier.check_sentence` (claim grounding of figures, citations and deontics, the as-at check, alignment) still runs over the FULL premise, unchanged. Acceptance: (a) for a sentence, the verdict, reasons and repair equal what the verifier gives on a premise holding only the kept candidates for the entailment step, and the full premise for the claim checks; (b) the window the judge's choice points to (`NLIResult.window`, the judged windows, `aligned` from the judge) is always a cited window, also when every kept candidate is `not_stated`; (c) a sentence with no cited passage that reaches the judge (should not happen; the reference rules require one) is judged on all candidates, and this is logged once at warning level without sentence text; (d) the judge's passage numbers in its prompt run 1..k over the kept candidates only. Prefer a wrapper around the judge's scorer (`Judge.score(premises, hypothesis)` receives the candidate texts) that the verifier is given per sentence, mapping kept indices back; read `legal_rag_verifier/verifier.py` and `judge.py` read-only (`uv run python -c "import legal_rag_verifier.verifier as v; print(v.__file__)"`). Do not copy or patch the verifier package.
- R2 Policy. Record the scope in the policy hash without editing `contracts.py`: add a `VERIFIER_CONFIGS` entry `"STRICT_FIGURES+CITED_JUDGE"` (same `STRICT_FIGURES` object) in `engine/chapterverse/audit/policy.py`; `build_policy` names it; `make_verifier` turns the cited scope on exactly when the policy names it (the old name keeps today's behaviour, for the gates and for comparison). Export a constant for each name.
- R3 Gates. `eval/judge_gate.py run` and `eval/heldout_modal.py` get `--judge-scope all|cited` (default `all`, today's behaviour byte for byte, including cache keys). For `cited`, the cited windows of a unit are fixed by this pre-registered rule: the premise windows whose coordinate equals the unit's excerpt coordinate (held-out: `excerpt_coordinate`), or is an ancestor or a descendant of it. Find the matching field for fresh2's units (read `~/Code/legal-rag-verifier/scripts/fresh_eval.py` and `fresh_battery.py` read only). If fresh2 units carry no excerpt coordinate, do NOT invent a rule: implement held-out only, make `judge_gate --judge-scope cited` exit with a clear message, and report what fields fresh2 units do have. Units where the rule matches no window are judged on all candidates and counted (`cited_fallback` in the summary). Output goes to a different `--out` subdirectory per scope (`.../cited/`) so caches never mix. `heldout_modal --dry` must report call counts and the estimated Modal cost for each scope, and the summed judge prompt characters per scope (no network).
- R4 Tests: engine wrapper (kept candidates, index mapping back, chosen window always cited when all are not_stated, fallback with no cited passage, claim checks still see an uncited window's figure), policy names and hashes (old name unchanged, new name default), gate scope flag (default unchanged cache keys; cited rule on a synthetic held-out unit with ancestor and descendant matches; fallback counted). No network.
- R5 Offline checks only: `uv run python -m eval.heldout_modal --dry --judge-scope all` and `--judge-scope cited` (print both cost estimates and character totals), `uv run python -m eval.judge_gate replay` (must equal today's replay output). Do not run `judge_gate run`, any `heldout_modal` without `--dry`, or anything that calls a provider.
